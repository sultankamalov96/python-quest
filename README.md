# Python-квест: условия, циклы, функции

Тренажёр для 9 класса: условные операторы, циклы, функции, списки и строки.
Чистые HTML + CSS + JavaScript: без сборщиков, без интернета, без сервера.

- **96 задач-пазлов** семи типов по 12 темам (по 8 задач на тему, все три уровня сложности);
- **11 игр**: робот (30 уровней), микромышь (10 уровней и турнир), черепашка (15), «Истина или Ложь», «Сколько раз?», «Ты — компьютер» (10),
  «Мемори», викторина (50 вопросов), дуэль на проекторе, сапёр (12), магазин на базаре (8);
- **тесты с оценкой 2–5**: «Основы Python», «Условные операторы», «Циклы» (по 60 вопросов), итоговый тест по Python и такой же по Dart (30 из 75 вопросов, 30 минут, до 25 баллов, результаты получает учитель), «Информатика, 4 класс» (60 вопросов) и «Основы информатики, 5 класс» (80 вопросов), в тестах по информатике есть картинки;
- **квест** на 8 станций с кодовым словом, очки, звёзды, 24 достижения;
- **режим учителя**: все ответы, фильтры, показ на проекторе, печать, настройки игр.

Весь код Python выполняет собственный интерпретатор (`js/engine.js`) прямо в браузере.

## Как открыть

**На компьютере.** Скачайте папку и откройте `index.html` двойным кликом. Интернет не нужен.

**На проекторе.** Откройте сайт, внизу нажмите «🎓 Режим учителя» и включите «📽 Режим проектора»:
шрифт станет крупным (код — от 24 px), контраст — высоким.

**Тесты.** Откройте `tests.html`. Страница проверяет интерпретатор и прогоняет через него каждую задачу,
каждый уровень и эталонные решения. Вверху должно быть «✔ Все проверки пройдены».

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте новый репозиторий (например, `python-quest`).
2. Нажмите **Add file → Upload files** и перетащите **всё содержимое** папки (файлы `index.html`, `tests.html`,
   `README.md` и папки `css`, `js`, `data`). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Deploy from a branch*,
   ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/python-quest/`.

> **После каждого обновления файлов** поменяйте метку версии в `index.html` (и в `tests.html`):
> найдите и замените метку (сейчас `?v=20261110`) на новую, например `?v=20261115`.
> Иначе браузеры учеников могут взять старые файлы из кэша.

## Настройки — `data/config.js`

| Параметр | Что делает |
|---|---|
| `teacherPin` | PIN по умолчанию для режима учителя и разблокировки теста. Его можно сменить и без правки файла — в режиме учителя (см. ниже). Если поменять PIN здесь, старые ссылки на тесты перестанут работать. |
| `questWord` | Кодовое слово квеста. 8 букв — по букве на станцию; другая длина делится поровну. |
| `points` | Очки за пазл: 100, −25 за подсказку, −10 за ошибку, минимум 25. |
| `maxSteps` | Лимит шагов интерпретатора (защита от бесконечных циклов). |
| `defaultSpeed` | Скорость анимации в играх по умолчанию: 1…5. |
| `exams` | Тесты по умолчанию: `count` — вопросов в попытке, `time` — минут на тест (0 — без ограничения), `grades` — пороги оценок в процентах (`5: 85, 4: 70, 3: 50`). |
| `results` | `url` — адрес скрипта Google Таблицы, куда приходят результаты итогового теста (см. «Результаты тестов для учителя»). Можно оставить пустым и подключить таблицу в режиме учителя. |
| `hidden` | Что скрыто от учеников, пока учитель не изменит это в режиме учителя (см. «Что видят ученики»). |
| `lock` | Блокировка при уходе с сайта: `'exam'` — только во время теста (по умолчанию), `'always'` — всегда, `'off'` — выключено. |
| `lang` | Язык интерфейса: `'ru'` или `'ky'` (см. ниже). |

Прогресс учеников хранится в браузере (localStorage) на каждом устройстве отдельно.
Сбросить его можно в режиме учителя.

## Как добавить задачу

Все задачи — в `data/tasks.js`, в массиве `TASKS`. Скопируйте похожую задачу и измените.
Общие поля у всех типов:

```js
{
  id: 'out-while-05',        // уникальный, латиницей
  type: 'output',            // parsons | blanks | output | bug | maze | match | flow
  topic: 6,                  // 1 if/else, 2 elif, 3 and/or/not, 4 вложенные, 5 for, 6 while, 7 break/continue, 8 циклы+условия,
                             // 9 def и параметры, 10 return и область видимости, 11 списки, 12 строки
  level: 2,                  // 1…3 звезды
  title: 'Робот без батарейки',
  story: 'Сюжет задачи. Можно `код в обратных кавычках` и **жирный**.',
  code: '...',               // код задачи (для parsons, flow, match — пустая строка '')
  inputs: ['7', '3'],        // необязательно: значения для input()
  hints: ['Намёк', 'Почти ответ'],   // ровно две подсказки
  explain: 'Объяснение после решения',
  data: { ... }              // зависит от типа, см. ниже
}
```

Правильные ответы почти никогда не пишутся вручную — их считает интерпретатор.

| Тип | `data` |
|---|---|
| **output** — Что выведет программа? | `{}` — ответ вычисляется из `code` |
| **parsons** — Собери код | `{ lines: [...строки с отступами...], distractors: ['строка-ловушка'], check: 'run', tests: [{ inputs: ['5'] }] }` — `check: 'run'` сравнивает вывод собранного кода с эталоном на тестах; `check: 'order'` — сверка порядка (можно добавить `alt` — другие допустимые порядки строк) |
| **blanks** — Заполни пропуски | в `code` пропуски пишутся `___1___`, `___2___`; `{ answers: { 1: ['elif'], 2: ['<', '!='] }, bank: ['elif', 'else', '<', ...] }` — в банке должны быть лишние плитки |
| **bug** — Найди баг | `{ line: 4, fixes: ['вариант 1', ...], correct: 0, tests: [{ inputs: ['12'] }] }` — исправление без отступа получит отступ исходной строки; для багов в отступах добавьте `raw: true` и пишите варианты с точным отступом |
| **maze** — Лабиринт | `{ inputLabels: ['a', 'b'], goal: '💎', avoid: ['👹', '💀'], ways: 2, solutions: [['7', '3'], ['1', '20']] }` — по одному решению на каждый путь |
| **match** — Соедини пары | `{ kind: 'code', pairs: [['код', 'вывод'], ...] }`; `kind` может быть `'range'` (слева `range(...)`), `'filter'` (слева условие для `n` от `from` до `to`), `'expr'` (выражение с `vars`) |
| **flow** — Блок-схема → код | как parsons плюс `chart`: `[{ t: 'start' }, { t: 'io', text }, { t: 'act', text }, { t: 'if', text, yes: [...], no: [...] }, { t: 'while', text, body: [...] }, { t: 'for', text, body: [...] }, { t: 'end' }]` |

После добавления **откройте `tests.html`**: если в задаче ошибка (код падает, ответ не сходится,
баг не проявляется, решение лабиринта не ведёт к сокровищу), она будет отмечена красным с пояснением.

## Тесты с оценкой

Раздел «📝 Тесты»: три теста по 60 вопросов — «Основы Python» (типы данных, арифметика, переменные, ввод-вывод),
«Условные операторы» и «Циклы». В каждой попытке — 20 случайных вопросов (выбор из 4 вариантов) в случайном порядке,
варианты тоже перемешиваются. В конце — оценка 2–5, процент и разбор каждого вопроса с объяснением.
Начатая попытка не теряется при случайном обновлении страницы.

В режиме учителя у каждого теста есть кнопки «Все вопросы с ответами» и «Печать варианта»
(бумажный вариант и отдельный лист с ключом ответов).

**Время и количество вопросов.** В режиме учителя у каждого теста есть «⚙️ Настройки теста»: сколько вопросов
в попытке (1–60) и сколько минут на тест (0 — без ограничения). «Сохранить на этом устройстве» — для компьютера,
на котором вы нажали кнопку. «🔗 Ссылка для учеников» — ссылка с этими настройками: отправьте её в чат класса,
и у каждого, кто её откроет, тест будет с вашими настройками. Если ученик изменит в ссылке цифры, она перестанет действовать.
Ссылка для учеников получается, когда сайт открыт с GitHub Pages (с диска компьютера она работает только на нём).
Во время теста идёт обратный отсчёт; когда время выйдет, тест завершится сам, а в результате будет отметка «Время вышло».

**Блокировка во время теста.** Если ученик во время теста переключится на другую вкладку, окно или приложение
(или обновит/закроет вкладку), сайт закроется экраном «🔒 Сайт заблокирован». Снять блокировку может только учитель —
вводит PIN и выбирает «Разблокировать и продолжить тест» или «Завершить тест сейчас». Ответы при этом сохраняются,
а число уходов с сайта показывается в результате теста (и при печати). Перезагрузка страницы или закрытие вкладки
блокировку не снимают. В режиме учителя блокировка не срабатывает. Режим меняется параметром `lock` в `data/config.js`.
Это защита от случайного и простого списывания, а не от взлома: ученик, который очистит данные браузера, снимет блокировку,
поэтому во время теста стоит следить за классом.

**Входной тест «Python: входной тест»** — параллельная форма итогового: остальные 105 вопросов тех же трёх тестов
(по 35 из каждого, с итоговым не пересекаются), 30 вопросов, 30 минут, 25 баллов, результат уходит учителю.
Нужен, чтобы сравнить результаты «до» и «после» (например, в педагогическом эксперименте).

**Итоговый тест «Python: итоговый тест»** — 75 вопросов: по 25 из «Основ Python», «Условных операторов» и «Циклов»
(через равный шаг по каждому тесту, чтобы попали все подтемы). В попытке 30 вопросов — по 10 из каждого теста, на всё 30 минут.
Вместо оценки — **баллы**: все верные ответы = 25 баллов (доля верных ответов от 25, с точностью 0,1:
26 из 30 верных = 21,7 балла). Это поле `points: 25` у теста; его можно поставить и другому тесту.
Перед началом ученик пишет фамилию, имя и класс, а результат после теста уходит учителю (см. ниже).
Вопросы не копируются: итоговый тест собирается из трёх тестов в конце `data/exams.js`, поэтому исправление вопроса
в исходном тесте сразу попадает и в итоговый.

**Итоговый тест «Dart: итоговый тест»** устроен так же: 75 вопросов — по 25 на темы «Основы Dart», «Условные операторы»
и «Циклы», в попытке 30 вопросов (по 10 из каждой темы), 30 минут, до 25 баллов, результат уходит учителю.
Вопросы лежат в отдельном файле `data/exams_dart.js`. Встроенный интерпретатор сайта понимает только Python, поэтому
ответы на вопросы с кодом Dart проверяются настоящим Dart SDK: `node tools/check_dart.js` (запускайте после правки вопросов).

### Результаты тестов для учителя

У сайта нет своего сервера, поэтому результаты собираются в **Google Таблице учителя**. Подключается один раз:
режим учителя → «📊 Результаты тестов» → «Подключить Google Таблицу», там пошаговая инструкция и кнопка
«Скопировать скрипт» (секретный ключ для просмотра уже вставлен в скрипт). Скрипт добавляется в таблицу через
«Расширения → Apps Script»; для проверки запускается функция `setup` (`doPost` и `doGet` вызывает сайт —
если запустить их кнопкой «Выполнить», Google покажет ошибку `postData`, это нормально). Затем скрипт разворачивается как веб-приложение с доступом «Все»; его адрес (`…/exec`) вставляется
в режиме учителя. Ученикам адрес приходит в ссылке на тест (Тесты → ⚙️ Настройки теста → 🔗 Ссылка для учеников),
или его можно один раз записать в `data/config.js` → `results.url`, тогда ссылка не нужна.

- Каждый результат: дата, ученик, класс, тест, баллы (или оценка — для тестов без `points`), верно / всего / процент, результат по каждому тесту-теме,
  время, число уходов с сайта, отметки «время вышло» и «завершил учитель».
- Учитель видит результаты на сайте: режим учителя → «📊 Открыть результаты» (фильтр по тесту и классу, поиск по имени,
  средняя оценка, «Скачать для Excel», печать) — и в самой Google Таблице (лист «Результаты»).
- Без интернета результат сохраняется на устройстве и уходит в таблицу, когда интернет появится.
  Повторная отправка не создаёт дубликатов.
- Ученики могут только отправлять результаты; посмотреть их можно только с ключом учителя.
  Подделать отправку технически можно (сайт открытый), поэтому для отметок за четверть сверяйтесь с классом.
- Отправлять результат учителю умеет любой тест: достаточно поставить ему `results: true` в `data/exams.js`.

**Тест «Информатика» (4 класс)** — 60 вопросов, 39 из них с картинками, по 3 темам: информация, сочетания клавиш,
основные и дополнительные устройства компьютера. Сочетания клавиш указаны для Windows.

**Тест «Основы информатики» (5 класс)** — 80 вопросов, 43 из них с картинками, по 7 темам: устройства компьютера,
информация и её свойства, единицы измерения, файлы и папки, рабочий стол и окна, безопасность в интернете, кодирование.
У каждого вопроса есть тема (`topic`), и в попытку вопросы берутся из всех тем поровну: при 20 вопросах — по 2–3 на тему.
Картинки — векторные рисунки в `js/pictures.js` (работают без интернета). В вопросе картинка задаётся полем `img: 'monitor'`,
а если варианты ответа — картинки, ставится `pics: true` и варианты пишутся ключами картинок: `options: ['keyboard', 'monitor', ...]`.

**Как добавить вопрос:** в `data/exams.js` допишите в нужный тест объект
`{ q: 'Текст', code: 'print(7 // 2)', options: ['3', '3.5', '4', '2'], explain: 'Пояснение', check: 'output' }`.
**Первый вариант — верный** (в тесте варианты перемешиваются). Если указать `check: 'output'`
(или `'count'` — число строк вывода, `'error'` — код с ошибкой), `tests.html` проверит ответ интерпретатором.

## Что видят ученики

Режим учителя → «👁 Что видят ученики»: галочками выбирается, какие **разделы** (Пазлы, Игры, Тесты, Квест, Достижения),
**тесты**, **игры** и **темы пазлов** видны ученикам. Снятая галочка — ученик не увидит этого ни в меню, ни на главной,
ни в списке, а если откроет адрес напрямую, попадёт на главную с сообщением «Учитель пока закрыл этот раздел».
Учитель в режиме учителя видит всё, скрытое помечено «🙈 скрыто».

- **С Google Таблицей** (см. «Результаты тестов для учителя») настройки уходят ученикам сами: сайт у учеников
  проверяет их при открытии, каждую минуту и при возврате в окно. Хранятся в свойствах скрипта таблицы.
- **Без таблицы** — кнопка «🔗 Ссылка для учеников»: кто откроет ссылку, получит эти настройки на своём устройстве.
- Начатый тест ученик может закончить, даже если учитель в это время скрыл его. Станция квеста открывает свою
  задачу или игру, даже если они скрыты.
- Скрытое по умолчанию (до первых настроек учителя) задаётся в `data/config.js` → `hidden`,
  например `['section:quest', 'test:final', 'game:duel', 'topic:12']`.
- Это не защита: ученик, который очистит данные браузера, до следующей проверки увидит всё.

## Как сменить PIN учителя

**В режиме учителя** (проще всего): «🎓 Режим учителя» → раздел «🔑 PIN учителя» → текущий PIN, новый PIN (4–8 цифр) дважды → «Сменить PIN».
Новый PIN сразу действует на этом устройстве. На устройствах учеников он заработает, когда они откроют новую ссылку на тест
(«Тесты» → «⚙️ Настройки теста» → «🔗 Ссылка для учеников») — до этого у них действует прежний PIN.
Кнопка «Вернуть PIN из config.js» отменяет смену на этом устройстве. Сам PIN нигде не хранится — только его отпечаток.

**Для всех устройств сразу:** поменяйте `teacherPin` в `data/config.js` и опубликуйте сайт заново.

Это защита от случайного входа, а не от взлома: код сайта открыт.

## Микромышь

Игра по мотивам соревнований Micromouse: мышь 🐭 не видит лабиринт — только стены рядом с собой — и ищет сыр 🧀 в центре.
Забега два: в первом мышь разведывает лабиринт, во втором (та же программа, но мышь помнит найденные стены)
должна дойти до центра кратчайшим путём. После уровня кратчайший путь показан пунктиром.

| Уровни | Что учат |
|---|---|
| 1–2 | 🕹 ведём мышь стрелками сами: разведка и кратчайший путь |
| 3–4 | правило правой руки (`while`, `if`, `elif`) и почему оно заходит во все тупики |
| 5–6 | лабиринты с кольцами: правая рука ходит по кругу, нужно «иди туда, где был реже» (`visits_left()` …) |
| 7 | волновой алгоритм (flood fill) на открытом лабиринте: списки списков, очередь, функция |
| 8–9 | волна в тумане — как у настоящих микромышей: неизвестные стены считаются проходами |
| 10 | 🎲 новый лабиринт при каждом запуске |

Команды: `forward()` / `forward(3)`, `left()`, `right()`, `back()`, `turn_to(d)`. Датчики: `wall_front()`, `wall_left()`,
`wall_right()`, `at_goal()`, `visits_left()`, `visits_front()`, `visits_right()`, `x()`, `y()`, `facing()`, `size()`,
`is_goal(x, y)`, `wall(x, y, d)` (стена, которую мышь уже видела; d: 0 — север, 1 — восток, 2 — юг, 3 — запад),
`show(dist)` — показать числа на поле. Мышь, сделавшая больше 10·n² шагов, останавливается — значит, ходит по кругу.

**🏁 Турнир мышей** (кнопка над уровнями) — для проектора: учитель вставляет программы учеников
(в уровне есть кнопка «📋 Скопировать программу»), все мыши бегут по одному лабиринту одновременно,
в конце — таблица мест по второму забегу. Размер лабиринта и число колец выбираются.

Уровни — в `data/levels.js` (`LEVELS.mouse`): `size`, `seed` (лабиринт уровня всегда один и тот же), `loops` (кольца),
`random`, `fog`, `manual`, `goals` — три звезды из `goal`, `lines`, `explore`, `shortest`, `shortest1`.
`tests.html` проверяет, что эталон каждого уровня получает три звезды.

## Как добавить уровень игры

Уровни — в `data/levels.js`, вопросы викторины — в `data/quiz.js`. Формат описан в комментариях в начале каждого раздела.

- **Робот** (`LEVELS.robot`): карта из 8 строк по 8 символов: `#` стена, `.` пусто, `R` робот, `$` монета,
  `O` яма, `F` финиш, `P` клетку нужно закрасить, `K` ключ, `D` дверь; `dir` — куда смотрит робот (`N E S W`),
  `maxLines` — строк для третьей звезды, `solution` — эталон. Вместо карты можно указать
  `random: 'corridor' | 'snake' | 'lanes' | 'maze' | 'paint' | 'doors'` — тогда карта генерируется заново при каждом запуске.
  Команды: `forward()` / `forward(3)`, `left()`, `right()`, `take()` (монета или ключ), `paint()`, `open()` (дверь впереди, нужен ключ).
  Датчики: `wall_ahead()`, `wall_left()`, `wall_right()`, `hole_ahead()`, `door_ahead()`, `coin_here()`, `key_here()`,
  `need_paint()`, `at_finish()`. Уровень пройден, когда робот на флажке и все клетки `P` закрашены.
- **Черепашка** (`LEVELS.turtle`): `solution` — эталонная программа, по ней рисуется образец и выбирается старт;
  `colors: true` — проверять цвет линий.
- **Ты — компьютер** (`LEVELS.tracer`): `code` с циклом и `vars` — столбцы таблицы. Таблицу строит интерпретатор.
- **Сапёр** (`LEVELS.minesweeper`): `rule` — код Python, который ставит `mine = True`; переменные `n`, `row`, `col`.
- **Магазин** (`LEVELS.bazaar`): `vars` — данные покупателя (`[мин, макс, шаг]`, `'day'`, `'number'`),
  `edges` — «пограничные» значения, `solution` — эталон кассира.
- **Викторина** (`data/quiz.js`): `tier` 1…5, `q`, `code`, 4 варианта `options`, `answer`, `explain`.
  Если указать `check: 'output'` или `check: 'count'`, ответ будет проверен интерпретатором.

«Истина или Ложь», «Сколько раз?», «Мемори» и «Дуэль» генерируют задания сами — их не нужно заполнять.

## Как добавить кыргызский язык

Все тексты интерфейса — в `js/i18n.js`. В разделе `I18N.ky` автоматически создаются те же ключи, что в `I18N.ru`,
с пустыми значениями. Впишите перевод в `ky` (например, `'nav.puzzles': 'Табышмактар'`)
и поставьте `lang: 'ky'` в `data/config.js`. Пока перевода нет, показывается русский текст.

Тексты задач, уровней и вопросов викторины лежат в `data/*.js` — для перевода сделайте копии этих файлов.

## Что умеет интерпретатор

Переменные, `int`, `float`, `str`, `bool`, `None`, списки; арифметика `+ - * / // % **` (как в Python,
включая отрицательные числа); `+= -= *=`…; сравнения и их цепочки (`0 < x < 10`); `and`, `or`, `not`;
`if / elif / else`, `while`, `for … in range(...)` и по строке/списку, `for x, y in …`, `break`, `continue`, `pass`;
генераторы списков `[x * 2 for x in range(5) if x > 1]` (словарей `{}` нет);
`print` (с `sep` и `end`), `input`, `int`, `str`, `float`, `len`, `abs`, `min`, `max`, `round`, `sum`;
f-строки, срезы строк, тернарный оператор;
функции: `def`, `return`, параметры по умолчанию, именованные аргументы, локальные переменные, `global`, рекурсия;
методы списков (`append`, `insert`, `remove`, `pop`, `sort`, `reverse`, `extend`, `index`, `count`)
и строк (`upper`, `lower`, `strip`, `split`, `join`, `replace`, `find`, `count`, `isdigit`, `isalpha`…),
`sorted`, `reversed`, `ord`, `chr`. Ошибки — на русском, с номером строки.

В пошаговой трассировке видны строки внутри функций.

**Не поддерживаются**: `class`, `import`, `try`, `lambda`, словари.
Сообщения об ошибках интерпретатора хранятся в самом `js/engine.js` (он работает и без интерфейса),
поэтому для перевода их нужно править там.
